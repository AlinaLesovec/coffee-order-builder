# Coffee Order Builder (Python)

Практическая работа 16.  
Реализация системы оформления заказа кофе с использованием шаблона **Builder**.

## 📌 Описание

Пользователь может пошагово собрать заказ кофе:

- база напитка
- размер
- тип молока
- сиропы
- сахар
- лед

Билдер выполняет валидацию параметров, рассчитывает цену и формирует человекочитаемое описание заказа.

## 🧱 Реализовано

### Immutable модель
Класс `CoffeeOrder` — неизменяемый объект заказа.

Поля:
- base
- size
- milk
- syrups (tuple)
- sugar
- iced
- price
- description

### Builder
Класс `CoffeeOrderBuilder` с fluent-интерфейсом:

- set_base()
- set_size()
- set_milk()
- add_syrup()
- set_sugar()
- set_iced()
- clear_extras()
- build()

### Валидация
- обязательны base и size
- сахар: 0..5
- сиропов максимум 4
- дубликаты сиропов игнорируются

### Ценообразование
Цена зависит от:
- базовой цены напитка
- размера
- молока
- сиропов
- льда
